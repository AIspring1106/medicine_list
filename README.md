# 医薬品リスト v1.2.7 revision 7

学内の学生の学習向上を目的としたPWAです。医薬品の販売名・一般名・薬効を使った入力式クイズと暗記カードを提供します。

## 起動・設定

1. ZIPを展開し、WebサーバーまたはローカルHTTPサーバーで公開します。PWAとService Workerの利用にはHTTPS、またはlocalhostが必要です。
2. 本ZIPには、今回アップロードされた `config.local.js` を `data/config.local.js` として含めています。管理者の既存設定ファイルを利用する場合は、このファイルを置き換えてください。
3. `SHARED_PASSWORD` が実際の共通パスワードであり、`PASSWORD_IS_DEFAULT` が `false` であることを確認してください。`LOGIN_SESSION_DAYS` は30日です。
4. Google OAuth・Google Sheets連携はrevision 4で削除済みで、revision 6にも含まれていません。旧設定にOAuth項目が残っていても参照しません。

**今回同梱した `data/config.local.js` は `change-this-password` / `PASSWORD_IS_DEFAULT: true` の初期テンプレートです。このままではログインできません。実際のパスワードに置き換え、`PASSWORD_IS_DEFAULT` を `false` にしてから公開してください。** `.gitignore` はこのファイルをGitへの誤登録から除外します。

## 医薬品CSV・XLSX・PDFの作成と読み込み

1. 医薬品リストを端末に **`.csv` または `.xlsx` ファイル** として保存するか、同じ表を含む **`.pdf` ファイル** を用意します。
2. CSV・XLSX・PDFの表は、A列＝販売名、B列＝一般名、C列＝薬効の3列にします。A1から下へ続く3列を読み込みます。
3. アップロードする前に、ファイルが **最新のデータ** であることを確認してください。
4. アプリの「データ入力」で複数のCSV・XLSX・PDFファイルを選択できます。候補一覧から使用するファイルを1つ選び、「選択したファイルを読み込む」を押してください。XLSXでは先頭ワークシートを使用します。PDFは文字を選択できる3列の表を全ページから抽出し、そのまま読み込みます。先頭行に列名は不要です。

CSV・XLSX・PDFファイルはブラウザー内で読み込みます。候補ファイルそのものはページ再読み込み後に保持されないため、未読み込みのファイルは再選択してください。読み込み済みデータは端末内のブラウザー保存領域に保持されます。空行・不正行・重複行は読み込み時に除外されます。PDFの解析にはMozilla PDF.js v6.5.438を使用します。初回のPDF読み込み時にライブラリ・Worker・文字マップ等をCDNから取得するため、インターネット接続が必要です。PDFファイル自体や表データはCDNへ送信しません。スキャン画像PDF、パスワード保護PDF、複雑な表・列境界の不明瞭なPDFは読み取れません。抽出結果を画面上で事前プレビューしないため、読み込み元PDFの列順（A列＝販売名、B列＝一般名、C列＝薬効）と内容を事前に確認してください。
## データの保存

医薬品データ、アプリ設定、学習履歴、誤答記録、ブックマークおよびログイン状態は、原則として利用端末のブラウザー内（localStorage等）に保存されます。サーバー同期や端末間共有は行いません。ログアウトしても学習データは削除されません。

## プライバシー・利用規約

- `privacy-policy.html`：プライバシーポリシー
- `terms-of-service.html`：利用規約（Terms of Service）

初回利用時および文書改訂時は、両文書への同意が必要です。同意した版と日時は端末内に保存します。

## セキュリティ上の重要事項

本アプリの共通パスワード照合はブラウザー側JavaScriptで行われます。`config.local.js` をWebサーバーで配信すると、GitHubにコミットしていなくても第三者が取得できる可能性があります。管理者からURLと共通パスワードを案内された人だけに利用させる運用は、サーバー側アクセス制御ではありません。**学外共有が禁止された機密データの保護を、この簡易ログインだけに依存させないでください。** 実運用前に、大学等が管理するサーバー側認証やVPN等を導入し、学内の情報セキュリティ担当者の承認を得てください。

## revision 5 の変更（履歴）

- 入力ファイルは `.csv`、`.xlsx`、`.pdf` に対応します。XLSXは先頭ワークシート、PDFは文字選択可能な表からA列相当＝販売名、B列相当＝一般名、C列相当＝薬効を読み込みます。ファイル本体はブラウザー内で解析され、アプリのサーバーへ送信しません。
- XLSX解析は同梱 `xlsx-reader.js` が行うため外部CDNへの接続は不要です。PDF解析は `pdf-reader.js` がMozilla PDF.js v6.5.438をCDNから遅延取得します。PDFのファイル本体は端末内にとどまりますが、初回読み込み時はネット接続が必要です。スキャン画像やパスワード保護PDFは対象外です。
- 医薬品データの削除ボタンはクイズ・暗記カードの両ホーム画面にあります。共通の読み込み済み医薬品リストだけを削除し、履歴・誤答・ブックマークは保持します。
- 起動時に公開版 `version.json` を確認します。更新がある場合はログイン前に「更新があります！」ダイアログを表示し、「後で」または「今すぐ更新」を選べます。
- 通知は利用者が「通知を有効にする」を押して許可した場合のみ利用します。アプリ終了中にも届く真のWeb Pushには、VAPID鍵・Push購読管理・サーバー配信基盤が別途必要であり、本パッケージには含めていません。
- ログインセッションはlocalStorageに30日間保存されます。期限内かつサイトデータが保持されていれば、再読み込み・アプリ再起動後もログイン画面を省略します。プライベートブラウズ、サイトデータ消去、ストレージ制限等では保持されない場合があります。

### config.local.jsについて（重要）

このアーカイブには、今回アップロードされたファイルを `data/config.local.js` として含めています。ただし、アップロードされた設定値は `SHARED_PASSWORD: "change-this-password"`、`PASSWORD_IS_DEFAULT: true` という初期テンプレートでした。この状態ではログインは許可されません。管理者は公開前に、`SHARED_PASSWORD` を実際の共通パスワードへ置き換え、`PASSWORD_IS_DEFAULT` を `false` に設定してください。`LOGIN_SESSION_DAYS: 30` は維持しています。

`data/config.local.js` は公開JavaScriptとしてブラウザーへ配信されるため、パスワードは利用者から確認可能であり、強い認証情報ではありません。学外共有禁止の医薬品データを守る用途では、サーバー側認証や学内ネットワーク制限を別途導入してください。`.gitignore` はこのファイルをGit追跡対象から除外します。ZIPには含まれますが、公開GitHubへそのままコミットしないでください。
